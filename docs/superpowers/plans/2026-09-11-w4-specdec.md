# W4 Speculative Decoding Implementation and Overnight Run Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to run this plan task-by-task in this session (Part A is CPU-only and was executed on 2026-09-11; Part B is an unattended GPU run with background jobs and monitoring, so a fresh subagent per task does not fit). Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Measure the decoding axis of the design spec (§3.1): five cells (8B FP8 none / n-gram; 4B none / EAGLE-3 / n-gram), each with a closed-loop grid and an open-loop Poisson sweep on natural-text prompts, in one GPU window on the desktop-shared RTX 4090, with the draft acceptance rate recorded per stage, and turn the result into paired tables (every accelerated cell against the `none` cell of its model at equal rate and seed) rebuilt by `make reproduce`.

**Architecture:** Part A (CPU only, before the window) extends the harness with spec-decode counters and a per-stage acceptance summary, a `--speculative-config` flag generated from `config/specdec/*.yaml`, a paired analysis module hooked into `batch_analysis.run`, a `batch.sh` that can run through the passthrough shim (and against the fake engine), a per-cell driver reusing the W2 chain's closed-loop → r_sat → open-loop → quarantine → promote pattern, a night script with a 20-minute GPU smoke gate, and a CPU dry run against `fake_vllm.py --specdec`. Part B (the GPU window) runs the smoke, then the five cells in value order, then rebuilds the tables.

**Tech Stack:** Python 3.12 (uv), vLLM 0.28.0 in WSL2 `Ubuntu-bench`, inference-perf 0.6.1 (`~/vllm-slo-lab/.venv-loadgen`), aiohttp shim (`slo-lab shim --policy passthrough`), bash drivers under `scripts/wsl/`, pytest, ruff.

## Global Constraints

- Engine flags frozen from W2/W3: `--max-model-len 4096 --gpu-memory-utilization 0.82 --max-num-seqs 256 --max-num-batched-tokens 2048`; env `VLLM_WSL2_ENABLE_PIN_MEMORY=1`, `VLLM_USE_FLASHINFER_SAMPLER=0`, `HF_HUB_OFFLINE=1`. Never raise 0.82. Only `--speculative-config` differs between the cells of a family.
- Prompts: inference-perf `synthetic` (Shakespeare corpus slices, random start offset per request), 108 in / 132 out tokens, `ignore_eos`, thinking off, completion API. Never `random` (ADR 0015 item 1).
- Closed-loop grid `1 8 32 128 256`, seed 1, `num_requests` `90 780 2800 6700 9000` times the cell's speed factor (`fp8-*` 1, `q4b-none` / `q4b-ngram` 2, `q4b-eagle3` 3; `NREQ_SCALE_*` in `w4-night.sh`), 60 s discard; a stage that still ends inside the discard is re-run once with 3x requests (`CLOSED_LOOP_SHORT`). Open-loop `{0.1, 0.25, 0.5, 0.75, 0.9} × r_ref`, seeds 1 2 3, 300 s per point, 60 s discard; r_ref = closed-loop r_sat of the family's `none` cell (ADR 0015 item 3).
- Spec-decode parameters: n-gram `num_speculative_tokens 3, prompt_lookup_max 4, prompt_lookup_min 2`; EAGLE-3 `num_speculative_tokens 3` (ADR 0015 item 4).
- Every cell runs through the passthrough shim on 8021 (vLLM on 8013); shim `upstream_errors` must be 0.
- Warm-up 100 sequential for the first stage of a session, 20 between stages (frozen, ADR 0007).
- Suspect rule: probe TPOT > best + 15 % in the cell, W/util < 2.0, Windows committed > physical → quarantine and re-run in a fresh session, max 2 rounds, never average.
- Cell labels `fp8-none`, `fp8-ngram`, `q4b-none`, `q4b-eagle3`, `q4b-ngram`; families `fp8`, `q4b`; evidence under `evidence/raw/w4/<cell>/{closed-loop/seed-1,open-loop/seed-N}/`, smoke under `evidence/raw/w4/smoke/`.
- Nothing pushed to GitHub, nothing paid, no GPU and no `vllm serve` during Part A; commits use `-c user.name=kuotunyu -c user.email=61350295+kuotunyu@users.noreply.github.com`, `GIT_ASK_YESNO=false`, stdin closed, no Co-Authored-By.
- WSL invocations only through script files: `MSYS_NO_PATHCONV=1 wsl.exe -d Ubuntu-bench -- bash <script>`; never `bash -c '…$var…'`. Files containing backslashes are written with the Write/Edit tools, never through a Bash heredoc.

## Findings that shaped the design (2026-09-11, read from the installed sources, no GPU)

- vLLM 0.28 `config/speculative.py`: n-gram needs an explicit `num_speculative_tokens` (`_verify_args` raises otherwise); with neither `prompt_lookup_*` set it defaults both to 5 with a "TODO tune, arbitrarily chosen" comment; with only `prompt_lookup_max` set it sets `min = max`. So the YAML must carry all three values.
- vLLM 0.28 `config/vllm.py` `_set_max_num_scheduled_tokens`: with a speculative config `max_num_scheduled_tokens` defaults to `max_num_batched_tokens` (2048); the only effect at 2048 is a "suboptimal, < 8192" warning (seen in the W1 EAGLE-3 log). The token budget is identical across cells.
- vLLM 0.28 `v1/spec_decode/metrics.py` `SpecDecodingProm`: counters `vllm:spec_decode_num_drafts`, `vllm:spec_decode_num_draft_tokens`, `vllm:spec_decode_num_accepted_tokens`, plus `vllm:spec_decode_num_accepted_tokens_per_pos{position}`; prometheus_client exposes Counters with a `_total` suffix (as for `vllm:request_success_total` in `metrics-names.txt`). The smoke verifies the exact names on the live server before any main-cell stage.
- inference-perf 0.6.1 `datagen/synthetic_datagen.py`: prompts are slices of `assets/shakespeare.txt` starting at a random offset drawn from a generator seeded with `base_seed`, tokenized to the exact length; the Poisson timer (`loadgen/load_timer.py`) uses an unseeded generator, as in W2.
- W1 (`evidence/raw/w1/matrix-load-check.jsonl`): Qwen3-4B KV 90,480 tokens at 0.90, with the EAGLE-3 head 83,952; at 0.82 roughly 75k / 69k, above the 61,440 that 256 requests of 240 tokens need, so `--max-num-seqs 256` should hold without preemption (smoke checks).
